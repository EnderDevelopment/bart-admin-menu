# Bart Admin Menu

Bart Admin Menu is a Minecraft plugin that provides an in-game administrative menu for server management. It offers a user-friendly interface with customizable options, allowing server administrators to quickly access essential commands and features. The plugin is designed to be lightweight, easy to install, and compatible with PaperMC servers.

## Install

1. Download the latest version of the Bart Admin Menu plugin from the GitHub repository.
2. Place the downloaded JAR file into the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Join the Minecraft server as a player with administrative privileges.
2. Type `/bart` in the chat to open the Bart Admin Menu.
3. Use the in-game menu to access various administrative commands and features.
